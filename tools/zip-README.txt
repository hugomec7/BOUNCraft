BOUNCraft 2.1 - Overshoot and bounce for EffectCraft

INSTALL
1. In EffectCraft: File > Scripts > Install ScriptUI Panel... and pick BOUNCraft.jsx
2. Restart EffectCraft.
3. Open it: Window > BOUNCraft.jsx

MANUAL INSTALL
Copy BOUNCraft.jsx to this folder, then restart EffectCraft:
%APPDATA%\EffectCraft\Scripts\ScriptUI Panels\

USE
Animate a property with two keyframes, select the layer, click Bounce It.

https://github.com/hugomec7/BOUNCraft
